Format explanation:
- Each ASCII value is converted to decimal digits
- Each digit is stored in 4 bits (nibble)
- Two nibbles packed per byte
- 0xF = unsigned sign nibble at end
- Example: 'h'=104 -> digits '104' -> nibbles [0,1,0,4,F]
          -> packed as 0x01, 0x04f (bytes: 0x01 0x4f)
